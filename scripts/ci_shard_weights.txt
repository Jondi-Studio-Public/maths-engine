# Measured test durations that scripts/ci_shard.py balances the CI shards by.
#
# One entry per line: "<seconds> <target>". Blank lines and "#" comments are ignored.
# A target is a test file ("tests/test_x.py") or one test function of a file
# ("tests/test_x.py::test_fn"). Seconds are wall-clock seconds on a CI runner (4 vCPU,
# pytest -n auto), summed over every parametrized case of the function.
#
# A file with any "::" entry is SPLIT: ci_shard.py parses it and hands each of its
# test functions to a shard separately, as a pytest node id. A function the file has
# but this list does not name still runs, once, at DEFAULT_FUNCTION_SECONDS, so a new
# test can never be dropped. A file with no entry is weighted by its size.
#
# Why: the five tests/test_mathgen_*.py sweeps are 10-110 KB but each runs every topic
# through a seed loop of make() with a SymPy check, 4-18 minutes per file on a runner.
# Balanced by size they stacked into two or three shards (measured on 48e3c6e: shards
# 0 and 11 took 23 and 24 minutes against a 30 minute limit). Measured 2026-10-13 as
# per-test CPU seconds on a 4-core machine, scaled by 0.575 to CI wall time (CI ran
# about 2.3 times slower, spread over 4 cores). Refresh with
#   pytest <file> -n 4 --durations=0
# and re-sum by function; only the ratios matter, so an approximate refresh is enough.
