# Measured test durations that scripts/ci_shard.py balances the CI shards by.
#
# One entry per line: "<seconds> <target>". Blank lines and "#" comments are ignored.
# A target is a test file ("tests/test_x.py") or one test function of a file
# ("tests/test_x.py::test_fn"). Seconds are wall-clock seconds on a CI runner (4 vCPU,
# pytest -n auto), summed over every parametrized case of the target.
#
# A file with any "::" entry is SPLIT: ci_shard.py parses it and hands each of its
# test functions to a shard separately, as a pytest node id. A function the file has
# but this list does not name still runs, once, at DEFAULT_FUNCTION_SECONDS, so a new
# test can never be dropped. A file with no entry is weighted by its size.
#
# Measured 2026-10-15 as the mean of two CI runs of PR 109, 32 shards (38670730744 and 38673089366, hosted ubuntu-24.04): every shard
# logs "ci-seconds: <summed per-test seconds> <target>" after its tests (scripts/ci_durations.py).
# Those sums run in parallel, so each is multiplied by one factor, 0.295 (the shards' total
# test-step wall seconds over their total summed seconds), to give wall seconds.
# To refresh: read those lines from a recent run's 32 shard logs, scale the same way, and replace
# this list. Only the ratios matter, so an approximate refresh is enough.
#
